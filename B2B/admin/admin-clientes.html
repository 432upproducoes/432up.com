Como pedir e gravar filtros

Coluna: origem_cliente
Nome exato: Nova Prospecção
(P maiúsculo — igual ao que já está no banco)

No chat, peça: filtro origem Nova Prospecção
Não use: nova prospecção | nova-prospeccao | NP

Gravar
• Ficha: Origem → Nova Prospecção → Salvar
• Código: origem_cliente = "Nova Prospecção"
• SQL: UPDATE co_clientes SET origem_cliente = 'Nova Prospecção' WHERE ...
